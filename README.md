# Лот — расширение для Chrome

Распакованное расширение для поиска объявлений Авито. Интерфейс на русском языке, данные и API-ключ сохраняются локально в профиле Chrome.

## Установка

1. Откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение» и выберите корень этого репозитория (папку с `manifest.json`).
3. Нажмите значок расширения. Появится боковая панель; поиск сам откроет отдельную вкладку Авито.

## Использование

Введите товар, город, цену «от» и «до» (можно заполнить одно поле) и требования. Расширение откроет страницы выдачи и объявления в отдельной вкладке. Держите боковую панель открытой во время поиска. Результаты сохраняются в профиле Chrome. «Сохранено» — отдельный список избранных объявлений. Результаты поиска показываются только при совпадении названия товара и диапазона цены; аксессуары отсекаются, если их не искали явно.

По умолчанию включён непрерывный режим: расширение плавно прокручивает выдачу небольшими шагами, открывает каждое ещё не просмотренное в текущем запуске объявление в отдельной вкладке и проверяет город, цену и тип товара. Выдача при этом остаётся на месте, после проверки продолжается прокрутка. Затем расширение переходит по страницам и после конца выдачи повторяет обход с паузой, пока вы не нажмёте «Остановить». В прогрессе показывается число просмотренных и найденных объявлений, а также причины исключения. Заголовок объявления не отсекается по буквальному совпадению слов с запросом: релевантность исходной выдачи определяет Авито, а расширение отдельно исключает явные аксессуары, если их не искали. При выключенном режиме действуют лимиты страниц и объявлений. В пределах одного запуска одно объявление проверяется только один раз. Галочка «При новом поиске проверять заново» разрешает повторную проверку уже сохранённых результатов при следующем запуске и обновляет карточки без дубликатов. Для непрерывного поиска держите боковую панель открытой.

В настройках можно выбрать OpenAI или DeepSeek, ввести свой API-ключ и модель. Предлагаемые названия моделей можно менять; наличие и цена модели зависят от провайдера. API оплачивается пользователем. Без ключа работает локальная проверка, которая помечает неполные сведения как требующие уточнения. Ключ хранится в `chrome.storage.local` и отправляется только выбранному API.

## Проверка разработки

`npm test` запускает тесты URL поиска, требований и локального анализа. `npm run check` проверяет синтаксис JavaScript. Зависимости npm не требуются; нужен Node.js 20 или новее.

## Ограничения первой версии

Авито меняет HTML и может показывать проверку человека. Расширение пробует включить на выдаче переключатель «сначала из города», если находит его подпись. Если переключатель не найден, об этом говорится в результатах; сами объявления всё равно фильтруются по городу. Ссылки с явно другим городом пропускаются без открытия. Если отдельное объявление не загрузилось или не читается, поиск продолжится со следующим; число таких ошибок видно в результатах. Капча останавливает поиск и оставляет соответствующую вкладку для проверки человеком. Автоматический поиск не гарантирует обход всех объявлений. Неизвестные города транслитерируются; проверьте открывшуюся выдачу. После капчи пройдите проверку и повторите поиск. Пауза срабатывает между действиями и не прерывает текущую загрузку страницы или API-запрос. Без ИИ проверка сложных формулировок ограничена буквальным совпадением слов: неопределённое остаётся вопросом продавцу.

Ключ API хранится через `chrome.storage.local`; доступ к нему есть у этого расширения и у человека с доступом к профилю Chrome. Не отправляйте файлы профиля другим людям. Передача описания выбранному провайдеру происходит только при включённом ИИ и заданном ключе.
